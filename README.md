# Maison Aurel — Concept Watch Boutique

A concept e-commerce website for a fictional luxury watch brand, designed and built by **Amirreza Ashab** as a portfolio piece.

🔗 **Live demo:** https://amirrezao.github.io/aurel/

## Overview
Maison Aurel is an imaginary watchmaker. This project explores an elegant, minimal boutique experience — product presentation, collection pages, and a shopping bag flow.

## Pages
- Home
- Product pages: Nocturne, Ivoire, Sanguine, Onyx
- Bag
- About

## Built with
- HTML, CSS, JavaScript
- Responsive layout
- SEO basics: unique titles and descriptions, canonical links, sitemap

## Note
Maison Aurel is a fictional brand created for demonstration purposes only. It is not a real business.
